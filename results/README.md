# Resultados

Esta carpeta reúne resultados consolidados y sus insumos de análisis. No contiene salidas temporales de nuevas ejecuciones; esas van a `artifacts/`, que está excluido del control de versiones.

| Carpeta o archivo | Contenido |
| --- | --- |
| `validation_20_problems/` | Planilla, figuras y trazas de la validación de branching sobre 20 problemas. |
| `branching_pattern_analysis/` | Resumen y análisis exploratorio de patrones de branching. |
| `analysis_20260910/` | Snapshot de análisis retrospectivo: datos derivados, scripts, informes y figuras. |
| `validation_hybrid_20260907/` | Reporte, protocolo, selecciones y ramas de la validación híbrida recibida. |
| `aligned_semantic_lookahead_20260910/` | Archivo original y extracción de la validación de lookahead semántico alineado. |
| `sheet_build_data/` | Datos que alimentan la construcción de la planilla de validación. |
| `presentation/` | Diagrama y presentaciones basadas en los resultados. |
| `report_artifact.json` | Registro estructurado del artefacto de reporte. |

## Procedencia

Las planillas y la bitácora tuvieron como fuente el espacio de trabajo compartido en Google Drive. Se mantienen aquí como copia local para documentar el análisis y facilitar una futura publicación. Las fuentes de Drive no se modifican desde este repositorio.

Los informes especifican su fecha y alcance. Las cifras exploratorias no deben interpretarse como resultados confirmatorios sin repetir el protocolo correspondiente.
